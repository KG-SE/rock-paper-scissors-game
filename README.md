## 🚀 Features
-  Real-time score tracking
-  Computer AI with delay
-  Sound effects
-  Reset game functionality
-  start/close game functionality

## 🎯 How to Play
1. Click on start button to play
2. Choose Rock, Paper, or Scissors  
3. Computer will generate its move  
4. Score updates automatically  
5. Use Reset button to restart game
6. Click on close button to closed the game
